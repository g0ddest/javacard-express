   https://github.com/licel/jcardsim
   Licensed under the Apache License, Version 2.0
   (https://www.apache.org/licenses/LICENSE-2.0). jCardSim's own LICENSE and
   NOTICE files are included in this jar under META-INF/.

   contains the classes of the Java Card API packages (javacard.*, javacardx.*),
   which jCardSim's build takes from Oracle's Java Card API jar; they come with
